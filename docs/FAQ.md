## General Questions

### What is this project?
See the [README](/README.md) for a full overview.

### How do I ask a question?
Open an issue using this [link](https://github.com/Loepker-James/enforce-rules/issues/new?template=question.yml)

Do **NOT** change the title, labels, and assignees. **ONLY** fill out the empty forms.

### What does "(s)" mean in the Code of Conduct?
It means either form applies, so "pattern(s)" means one or more patterns. See [§1.4 (Notation)](https://github.com/Loepker-James/enforce-rules/blob/main/CODE_OF_CONDUCT.md#14-notation).
