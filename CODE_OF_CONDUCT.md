# Code of Conduct

## 1. Purpose
This project aims to maintain a respectful, safe, and productive environment for all contributors.

## 2. Expected Behavior
Contributors should:
* Be respectful toward others.
* Provide constructive feedback.
* Follow project rules and maintainer instructions.
* Keep discussions focused on the project.
* Use inclusive and professional language.

## 3. Unacceptable Behavior
The following actions are not allowed:
* Harassment, insults, or personal attacks.
* Threats or intimidation.
* Hate speech or discriminatory language.
* Leaking exploits or posting harmful code.
* Spam, trolling, or repeated off-topic comments.
* Impersonation or ban-evasion attempts.
* Intentionally disrupting project development.

## 4. Enforcement
Maintainers may take any of the following actions:
* Issue a warning.
* Hide or delete harmful content.
* Block the user from the repository.
* Report violations to GitHub Trust & Safety.
* Remove contributions that violate this Code of Conduct.

## 5. Reporting
To report violations:
* Use GitHub’s “Report abuse” feature on the user’s profile.
* Or open a private security report via the repository’s Security tab.

Reports will be handled confidentially.

## 6. Consequences
Violations may result in:
* Content removal.
* Temporary or permanent blocking from the project.
* Escalation to GitHub Trust & Safety.
* Removal of contributions that violate project rules.

Severe or repeated violations may lead to permanent removal from the community.
